# Express, mongodb, jws

## Необходимые компоненты

Для запуска проекта установите Docker Desktop и запустите Docker Engine.

## Запуск

Перейдите в корневую папку проекта и в терминале запустите команду docker-compose up.

## Порты для подключения

80 - nginx сервер через который идут все запросы.

8081 - веб-административный интерфейс для MongoDB.

15672 - веб-административный интерфейс для RabbitMQ.
